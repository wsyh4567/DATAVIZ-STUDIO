# DataViz Studio 功能增强需求文档

## 项目概述

**项目名称**: DataViz Studio 功能增强  
**目标**: 集成 D-Tale 和 PyGWalker 的核心功能，提升数据清洗、数值处理和图表可视化能力  
**优先级**: 高  
**预计工期**: 3-4 周

---

## 业务目标

### 核心目标
1. 提供完整的数据清洗工具集（20+ 功能）
2. 实现高级数值处理能力（15+ 功能）
3. 增强图表智能化和交互性（30+ 图表类型）
4. 保持 Python 优先架构，所有操作可导出为可执行代码

### 成功指标
- 功能完整性: 实现 80% 的 D-Tale 数据清洗功能
- 代码质量: 测试覆盖率 > 80%
- 用户体验: UI 响应时间 < 1秒
- 代码生成: 所有操作生成正确的 Python 代码

---

## 功能需求

### Phase 1: 核心数据清洗功能（Week 1）

#### FR-1.1 列拆分功能
**优先级**: 高  
**描述**: 按分隔符将一列拆分为多列

**功能要求**:
- 支持常见分隔符（逗号、空格、分号、竖线）
- 支持自定义分隔符
- 可指定拆分数量（2列、3列、全部）
- 自动生成新列名或使用用户指定名称
- 生成可执行的 Python 代码

**参考**: D-Tale `column_builders.py` 的 `SplitColumnBuilder`

#### FR-1.2 列合并功能
**优先级**: 高  
**描述**: 将多列合并为一列

**功能要求**:
- 支持选择多列
- 可指定分隔符
- 可选择是否删除原列
- 生成可执行的 Python 代码

#### FR-1.3 查找替换功能
**优先级**: 高  
**描述**: 在列中查找并替换值

**功能要求**:
- 支持精确匹配
- 支持正则表达式
- 可选择是否区分大小写
- 显示替换预览
- 生成可执行的 Python 代码

#### FR-1.4 字符串清理功能
**优先级**: 中  
**描述**: 清理字符串列的空格和格式

**功能要求**:
- 去除前导/尾随/所有空格
- 大小写转换（大写、小写、标题、首字母大写）
- 提取子字符串
- 生成可执行的 Python 代码

---

### Phase 2: 数值处理功能（Week 2）

#### FR-2.1 数值分箱功能
**优先级**: 高  
**描述**: 将连续数值分组为离散区间

**功能要求**:
- 等宽分箱（Equal Width）
- 等频分箱（Equal Frequency）
- 自定义边界分箱
- 可指定标签
- 生成可执行的 Python 代码

**参考**: D-Tale 的分箱功能

#### FR-2.2 标准化和归一化功能
**优先级**: 高  
**描述**: 数值缩放和标准化

**功能要求**:
- Z-score 标准化
- Min-Max 归一化（可指定范围）
- 鲁棒缩放（使用中位数和四分位距）
- 生成可执行的 Python 代码

#### FR-2.3 滚动窗口函数
**优先级**: 中  
**描述**: 时间序列和滚动计算

**功能要求**:
- 滚动平均（rolling mean）
- 滚动求和（rolling sum）
- 滚动标准差（rolling std）
- 指数平滑（exponential smoothing）
- 可指定窗口大小
- 生成可执行的 Python 代码

#### FR-2.4 累积函数
**优先级**: 中  
**描述**: 累积计算

**功能要求**:
- 累积和（cumsum）
- 累积积（cumprod）
- 累积最大/最小值（cummax/cummin）
- 生成可执行的 Python 代码

---

### Phase 3: 图表功能增强（Week 3）

#### FR-3.1 智能字段识别
**优先级**: 高  
**描述**: 自动推断字段类型和角色

**功能要求**:
- 自动识别字段类型（数值、时间、分类、有序）
- 自动识别字段角色（维度、度量）
- 生成字段元数据（唯一值数、缺失值、统计信息）
- 在 UI 中显示字段面板

**参考**: PyGWalker 的字段推断逻辑

#### FR-3.2 字段面板组件
**优先级**: 高  
**描述**: 可视化字段面板

**功能要求**:
- 分组显示维度和度量
- 显示字段图标（📊 数值、📅 日期、🔤 文本）
- 显示字段统计信息
- 悬停显示详细信息
- 支持拖拽（可选）

#### FR-3.3 动态参数面板
**优先级**: 高  
**描述**: 根据图表类型动态显示参数

**功能要求**:
- 根据图表类型显示必需参数和可选参数
- 参数分组（基础、高级、样式）
- 参数验证（字段类型匹配）
- 智能推荐字段

#### FR-3.4 新增图表类型
**优先级**: 中  
**描述**: 扩展图表类型库

**功能要求**:
- Plotly: 面积图、瀑布图、雷达图、极坐标图、等高线图、3D曲面图
- Seaborn: 配对图、联合图、回归图、分类图
- 所有图表生成 Python 代码

## 非功能需求

### NFR-1 性能要求
- 数据操作响应时间 < 1秒（10万行以内）
- 图表渲染时间 < 2秒
- 代码生成即时响应

### NFR-2 代码质量
- 单元测试覆盖率 > 80%
- 所有公共函数有文档字符串
- 遵循 PEP 8 代码规范
- 使用类型提示

### NFR-3 用户体验
- 操作流程直观易懂
- 错误提示清晰友好
- 支持操作撤销/重做
- 提供操作预览

### NFR-4 可维护性
- 模块化设计，职责清晰
- 服务层、组件层、页面层分离
- 代码可复用
- 文档完整

---

## 技术约束

### 架构约束
- 必须遵循 Python 优先架构
- 所有图表由后端生成
- 前端使用 Dash/Plotly
- 数据处理使用 Pandas

### 兼容性约束
- Python 3.8+
- 支持常见数据格式（CSV、Excel、JSON）
- 生成的代码可在标准 Python 环境运行
