### 5. 数据加载服务 ✅

**`services/data_loader.py`**：

**支持格式**：
- CSV / TSV
  - 自动检测编码（chardet）
  - 智能推断分隔符（`,` / `\t` / `;` / `|`）
  - 自动识别表头行
- Excel (.xlsx / .xls)
  - 使用 openpyxl 引擎
  - 默认加载第一个 Sheet
- JSON
  - 支持数组格式：`[{...}, {...}]`
  - 支持嵌套对象（自动展平）

**示例数据集**：
- 内置 3 个经典数据集（无需外部依赖）
- 使用 numpy 随机生成，保证可复现

### 6. 数据管理器 ✅

**`core/data_manager.py`**：

**核心功能**：
- 单例模式（全局唯一实例）
- 多 DataFrame 存储（字典：名称 → DataFrame）
- 活跃数据集追踪
- Undo / Redo 操作历史栈（最多 50 步）
- 数据集元数据计算
  - 行数、列数
  - 内存占用（MB）
  - 数据类型
  - 来源信息

**API 示例**：
```python
dm = DataManager()
dm.add_dataset("sales", df)
dm.active_name = "sales"
meta = dm.get_meta()  # DatasetMeta 对象
dm.snapshot("删除列 age")
dm.undo()
```

## 🚀 下一步：Phase 2

### 核心目标

实现**图表工作室**，提供 Tableau / Power BI 级别的拖拽式图表创建体验。

### 主要任务

1. **字段面板**
   - 自动分类：度量（数值）vs 维度（分类/日期）
   - 拖拽到图表区域
   - 聚合方式选择（SUM / AVG / COUNT 等）

2. **图表类型选择器**（10+ 种）
   - 比较：柱状图、分组柱状图、堆叠柱状图、条形图
   - 趋势：折线图、面积图、堆叠面积图
   - 分布：直方图、箱线图、小提琴图
   - 关系：散点图、气泡图、热力图
   - 占比：饼图、环形图

3. **智能图表推荐**
   - 根据字段类型自动推荐最佳图表
   - 不兼容的图表灰显 + 提示原因

4. **样式配置面板**
   - 主题预设（12+ 套）
   - 调色板（D3 / ColorBrewer）
   - 标题/副标题编辑
   - 轴配置（标签、范围、刻度）
   - 图例配置（位置、方向）

5. **图表导出**
   - PNG / SVG / PDF（高清静态）
   - HTML（保留交互功能）
   - 复制到剪贴板

### 预计时间

3 周（按原计划）
