#### 2. 状态管理
使用dcc.Store进行状态管理：
```python
dcc.Store(id='original-data-store')  # 原始数据
dcc.Store(id='preview-data-store')   # 预览数据
dcc.Store(id='pipeline-store')       # 操作流水线
dcc.Store(id='undo-redo-store')      # 撤销重做状态
```
