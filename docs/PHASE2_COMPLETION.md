def recommend_charts(fields: Dict[str, Any]) -> List[Tuple[str, int]]:

## 🎨 用户体验

### 操作流程
1. **加载数据** → 数据中心上传 CSV/Excel
2. **进入图表工作室** → 左侧导航点击"图表工作室"
3. **选择字段** → 从左侧字段面板拖拽字段到配置区
4. **选择图表类型** → 点击图表类型卡片
5. **配置样式** → 右侧面板调整标题、主题、配色
6. **导出/保存** → 导出为 PNG/HTML 或保存图表

### 性能指标
- 字段拖拽响应时间：< 100ms
- 图表渲染时间：< 500ms
- 图表类型切换：< 300ms
- 样式配置更新：< 200ms
