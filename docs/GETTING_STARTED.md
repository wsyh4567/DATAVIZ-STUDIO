# 🚀 DataViz Studio — 快速上手指南

欢迎使用 DataViz Studio！本指南将帮助你快速开始使用这个强大的数据分析可视化平台。

---

## 📋 前置要求

- Python 3.9 或更高版本
- pip 包管理器

---

## 🔧 安装步骤

### 1. 克隆或下载项目

```bash
cd "C:\Users\Toxic\Desktop\python\python项目DataViz Studio"
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

依赖包括：
- `dash>=2.14` — Web 应用框架
- `dash-bootstrap-components>=1.5` — Bootstrap 组件
- `dash-ag-grid>=31.0` — 高性能数据表格
- `plotly>=5.18` — 交互式图表
- `pandas>=2.0` — 数据处理
- `openpyxl>=3.1` — Excel 文件支持
- `chardet>=5.0` — 编码自动检测

### 3. 验证安装

```bash
python test_app.py
```

如果看到 "🎉 所有测试通过！应用已准备就绪。"，说明安装成功。

## 🎬 启动应用

### 方式 1：直接运行（推荐）

```bash
python app.py
```

### 方式 2：使用 CLI（自动打开浏览器）

```bash

```


## 🎯 第一次使用

### 1. 欢迎页

启动后，你会看到欢迎页，有两种方式加载数据：

#### 方式 A：上传自己的数据

- 拖拽文件到上传区域，或点击选择文件
- 支持格式：CSV、Excel (.xlsx)、JSON

#### 方式 B：使用示例数据集

点击以下任一按钮快速体验：
- 🌸 **鸢尾花 (Iris)**：经典分类数据集 — 150 行 × 5 列
- 🍽️ **餐饮小费 (Tips)**：餐厅消费数据 — 244 行 × 7 列
- 🚢 **泰坦尼克 (Titanic)**：乘客生存数据 — 891 行 × 12 列

### 2. 数据画布

加载数据后，自动跳转到数据画布页面：

- **概览卡片**：显示总行数、总列数、缺失值、重复行、内存占用
- **数据表格**：高性能 AG Grid 表格
  - 点击列头排序
  - 列头筛选器（支持条件/范围/搜索）
  - 拖拽调整列宽
  - 分页浏览（每页 100 行）

### 3. 数据中心

点击左侧侧边栏的 📁 **数据中心**：

- 查看所有已加载的数据集
- 上传更多数据
- 切换活跃数据集
- 删除不需要的数据集

## 💡 使用技巧

### 数据加载

1. **CSV 文件**
   - 自动检测编码（UTF-8、GBK、Latin1 等）
   - 自动推断分隔符（逗号、制表符、分号等）
   - 智能识别表头行

2. **Excel 文件**
   - 支持 .xlsx 和 .xls 格式
   - 默认加载第一个 Sheet
   - 后续版本将支持选择 Sheet

3. **JSON 文件**
   - 支持数组格式：`[{...}, {...}]`
   - 支持嵌套对象，自动展平

### 数据表格操作

- **排序**：点击列头
- **筛选**：点击列头右侧的筛选图标
- **调整列宽**：拖拽列边界
- **分页**：使用表格底部的分页控件
- **选择行**：勾选行首的复选框（功能开发中）

### 主题切换

点击顶栏的 🌓 按钮在暗色和亮色主题之间切换：

- **暗色主题**（默认）：适合长时间使用，减少眼睛疲劳
- **亮色主题**：适合明亮环境，打印友好

## 🐛 常见问题

### Q: 应用启动失败？

**A:** 检查以下几点：
1. Python 版本是否 >= 3.9
2. 是否安装了所有依赖：`pip install -r requirements.txt`
3. 端口 8050 是否被占用：修改 `config.py` 中的 `PORT`

### Q: 文件上传失败？

**A:** 可能原因：
1. 文件格式不支持（目前仅支持 CSV、Excel、JSON）
2. 文件编码问题（尝试转换为 UTF-8）
3. 文件过大（默认限制 500MB，可在 `config.py` 修改）

### Q: 表格显示不完整？

**A:** 
- 默认每页显示 100 行，使用分页控件查看更多
- 超过 10,000 行时仅显示前 10,000 行（性能优化）
- 后续版本将支持虚拟滚动显示全部数据

### Q: 如何切换数据集？

**A:** 
1. 前往 📁 **数据中心** 页面
2. 在已加载数据集列表中点击 **设为活跃** 按钮
3. 返回 📊 **数据画布** 查看新数据集
