## 🐛 已知问题

### 1. 依赖版本警告（低优先级）

**问题描述**：
```
RequestsDependencyWarning: urllib3 (2.3.0) or chardet (6.0.0.post1)/charset_normalizer (3.4.1) doesn't match a supported version!
```

**影响范围**：
- 仅警告信息，不影响功能
- 应用正常运行

**解决方案**：
- 可选：更新 urllib3 或 chardet 到兼容版本
- 或：在 requirements.txt 中固定版本

**优先级**：低
